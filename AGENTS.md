## Portal architecture
- Keep this wireframe client-only with in-memory sample requests; it demonstrates approval workflows without calling or implying real external automation.
- Define team services in a shared catalogue module so cards and request pickers use the same service registry.
- Keep visual roles and responsive styles in the global design system so laptop and mobile share a consistent experience.
