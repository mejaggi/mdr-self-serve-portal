# MDR Self-Serve Portal

You are the CTO of the organization planning to build a self-service portal which is Tech for Tech. The portal would automate a lot of mundane things that are currently done manually and would enable the application, infrastructure and business teams. Examples such as joiner/ leaver, AD group creation etc should all be done through the app. Create a wireframe UI that can be used for this. The UI should be both for laptops and mobile and should use a card framework for each of the teams.
